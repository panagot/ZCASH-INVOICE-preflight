About ZEC Invoice Preflight

Compose-time ZIP-321 validation for Zcash merchants. The thermal desk is the demo; the durable deliverable is shared checks, fixtures, CLI doctor, and handoff schema v1 for BTCPay companion integration.

Naming

Public name and npm package: zcash-invoice-preflight. Handoff schema id (stable contract): btcpay-zec-helper.handoff/v1.

In scope

  • Preflight module with stable fail codes
  • Fixture corpus + CLI doctor (exit 0 pass / 1 fail)
  • Handoff JSON v1 for BTCPay plugin authors
  • Deployed merchant desk + customer pay page (client-side)

Explicit non-goals

  • Live chain detection (mock status lane only)
  • BTCPay Server plugin merge in the current milestone
  • Lightwalletd / Zaino observatory dashboards
  • Exchange deposit monitoring

Privacy

The merchant desk runs in your browser. Invoice fields and session history use local storage only — no server upload in this demo. The customer pay page reads a share token from the URL hash.
